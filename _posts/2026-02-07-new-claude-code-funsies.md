<p>Opus 4.6 came out this week (not the Sonnet 5 that was promised&#8230; a guy can still dream) and Claude Code got a bunch of new features - some publicised and some less so.</p><p><strong>Agent Swarms</strong></p><p><a href="https://x.com/NicerInPerson/status/2014989679796347375">Mike Kelly</a> actually discovered this feature a few days before it came out; it was already in the Claude Code build but hidden behind a secret feature flag.</p><blockquote class="tweet-embed">
  <p>I managed to unlock a crazy new hidden feature in Claude Code called Swarms. You&#39;re not talking to an AI coder anymore. You&#39;re talking to a team lead. The lead doesn&#39;t write code - it plans, delegates, and synthesizes. When you approve a plan, it enters a new &quot;delegation mode&quot;</p>
  <div class="post-embed-meta"><a href="https://x.com/NicerInPerson/status/2014989679796347375">Mike Kelly @NicerInPerson</a> &#183; <span>24 Jan 2026</span></div>
